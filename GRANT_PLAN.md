# Proposed BlueDot Rapid Grant project

Request: $4,000. This is a proposed budget, not an approved award.

I will handle engineering, dataset development, experiment design, and analysis.
The budget is $250 for OpenRouter pilots, $2,800 for the main study, $900 for
reliability and follow-up evaluations, and up to $50 for storage and backup.
API allocations include credit purchase fees and will be refined using pilot costs.

The target is approximately 200 matched pairs and eight fixed model versions.
At 400 items, five conditions, two answer orderings, and separate repeated controls,
one full pass is **38,400 responses**, before additional epochs. The earlier 32,000
estimate omitted repeated controls. Measured token costs, including reasoning,
determine the affordable repetition schedule. Freeze that schedule before the main
study and discuss material scope changes with the funder.

## Milestones

1. Pilot model access, response formatting, reasoning budgets, and token cost.
2. Expand and review the dataset, documenting sources and changes.
3. Freeze the protocol and complete the main study with traceable logs.
4. Run separately labelled robustness checks and publish reproducible analysis.
5. Improve spending controls, provider tracking, installation, and recovery.

The current release adds versioned runs, cell-level resume, consistent platform
entry points, and stricter reporting. It remains a prototype. A dependable release
for other researchers is the funded milestone. Success includes useful null
results. Mock-model checks are not empirical research findings.
