# Contributing

Useful contributions include question review, reproduction, statistical checks,
and provider compatibility. Run `python -m pytest -q` and
`python scripts/validate_dataset.py --quiet`. Also run a full mock panel when
changing execution or reporting. Document measurement changes in the changelog
and protocol.

AI-assisted contributions are welcome. Contributors remain responsible for
understanding and checking changes, respecting third-party licenses, and describing
material AI assistance honestly. Do not claim checks you have not run.

Never include API keys or unreviewed logs. Public findings should include versioned
settings, analysis, limitations, and supporting evidence.
