# False Floor

False Floor studies whether an AI model's measured performance changes when it is
told that its score could affect deployment. It compares matched ordinary and
safety-relevant questions while changing evaluation framing.

The project builds on existing sandbagging and evaluation-awareness research.
Its intended contribution is a small, inspectable workflow that other researchers
can run and extend. The first release is a prototype with 20 question pairs,
a documented protocol, and automated reporting.

The next milestone is a larger reviewed dataset and a reproducible study across
model families. Reliable evaluation infrastructure is the longer-term direction.
Findings will include limitations and null results.
